# CSS-143

## Program 03 — PC Build Component Hierarchy

### Files
- `src/Component.java` — Base class representing a single PC hardware component (name, price, description)
- `src/PCBuild.java` — Manages an `ArrayList` of `Component` objects and computes total build cost
- `src/Driver.java` — Entry point; constructs a `PCBuild`, adds components, and prints the result

### How to Run
```
javac src/*.java
java -cp src Driver
```
